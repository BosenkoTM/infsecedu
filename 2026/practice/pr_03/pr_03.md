# Главное правило анализа

В отчёте необходимо различать три категории.

| Категория | Что означает |
|---|---|
| **Факт** | событие прямо присутствует во входном журнале |
| **Гипотеза** | возможное объяснение нескольких фактов |
| **Дополнительная проверка** | сведения, которых в исходных данных нет, но они нужны для подтверждения гипотезы |

Пример:

> **Факт:** в 08:47:41 выполнен успешный вход `teacher.ivanova` с `203.0.113.77` (`A03`).  
> **Гипотеза:** учётная запись могла быть скомпрометирована после перехода по ссылке из письма.  
> **Дополнительная проверка:** запросить сведения о втором факторе, user-agent, журнал прокси/браузера и подтверждение пользователя.

Нельзя писать:

> «Преподаватель передал пароль злоумышленнику».

Такого факта во входных данных нет.
