# Чек-лист перед сдачей ПР1

- [ ] Добавлено не менее 5 активов.
- [ ] Для активов заполнены C/I/A.
- [ ] Обоснованы 5 критичных активов.
- [ ] Добавлено не менее 3 потоков данных.
- [ ] DFD содержит минимум 2 доверительные границы.
- [ ] Все рисунки представлены Mermaid-кодом.
- [ ] Описана модель источников угроз.
- [ ] Сформулировано не менее 12 сценариев.
- [ ] Присутствуют все обязательные классы сценариев.
- [ ] Для каждого сценария есть запись в реестре рисков.
- [ ] Для 5 приоритетных рисков обоснованы P и I.
- [ ] Для приоритетных рисков предложено минимум 2 меры разных типов.
- [ ] Остаточный риск пересчитан и объяснён.
- [ ] Выполнены 3 задания индивидуального варианта.
- [ ] Подготовлен фрагмент политики на 1–2 страницы.
- [ ] Подготовлена памятка для педагога.
- [ ] В выводе выделены 3 риска для образовательного процесса.
- [ ] В материалах нет реальных персональных данных.
