# Материалы студента — ПР1

Начните с файла [`Практическая_работа_01.md`](Практическая_работа_01.md).

## Исходные материалы

- `case_description.md` — развёрнутый кейс;
- `assets_initial.csv` — неполная инвентаризация активов;
- `data_flows.csv` — неполный перечень потоков данных;
- `threat_scenarios_template.csv` — шаблон сценариев угроз;
- `risk_register_template.csv` — шаблон реестра рисков;
- `risk_scales.md` — шкалы P/I и интерпретация риска;
- `measures_catalog.md` — справочник классов мер;
- `policy_fragment_template.md` — шаблон локальной политики;
- `report_template.md` — шаблон отчёта;
- `diagrams_mermaid.md` — Mermaid-заготовки;
- `variants_25.md` — 25 индивидуальных вариантов;
- `variants_25.csv` — варианты в табличном формате;
- `grading_rubric.csv` — критерии оценивания.
- `threat_sources_template.csv` — шаблон модели источников угроз;
- `critical_assets_justification_template.csv` — обоснование критичных активов;
- `pedagogical_memo_template.md` — шаблон памятки педагогу;
- `submission_checklist.md` — чек-лист перед сдачей;
- `references.md` — минимальные источники;


Все данные синтетические.
